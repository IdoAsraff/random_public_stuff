The following guide will help you create a character for the Caverns of Thracia open-table campaign ran by me - Ido Asraff. The end result should be a pdf (or 2 pdfs, one for spells - see below) that you either print yourself or send me for printing. **We use pencil&paper only during play.**

Note: The guide uses d&dbeyond; if you'd rather use another tool, or create your character manually, that's fine, but you still need to read this guide, to understand this campaign's character guidelines. 

1. go to dnd beyond character builder online (https://www.dndbeyond.com/characters/builder) and choose Standard. If you need help ask Ido. Note: we won't dnd-beyond during play, it just helps us quickly make the character.

2. choose name and the following options. **important - we play in 5e, not 5.5e**:
![[Pasted image 20260810092719.png|342]]![[Pasted image 20260810092220.png|347]]

3. choose class (cant choose blood hunter!). characters *always* start at level 1

4. choose background and skills that come with it. IGNORE all of these:
![[Pasted image 20260810092532.png|504]]

5. choose race ("species") and complete what's necessary

6. insert ability scores after manually rolling (ask me if you need help)

7. choose equipment - choose starting equipment (not gold). make sure you start with 10gp. IMPORTANT: make sure to click "use" on backpack and "wielding" for ALL weapons you have. example of how it should look when you're done:
![[Pasted image 20260810094414.png|455]]

8. export to pdf. if you want, you can now delete the dnd-beyond character you just created. we will not use it during play.

9. regarding spells: if your character has spells you might need to look-up during play, i recommend creating a pdf for your spells as detailed bellow, so we can print it too. here's how I recommend doing it:
	1. choose spells for your character using dndbeyond
	2. go to this website: https://www.thievesguild.cc/spells/spellcards
	3. choose **Color**: *Black & White*, **Verbal Component:** *Ancient (Latin-esque)*, check *Legacy*
	4. search for your spells, then click *Show Cards*
	5. print the page using the browser (i.e. ctrl+p) and you should get your spells in a neat pdf
